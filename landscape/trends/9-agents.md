# Agents

**The trend.** The market is moving from chat to agents, from tools that answer to tools that do finished work.

**The evidence.** OpenAI paired GPT-5.6 with a work agent that produces finished documents and spreadsheets, and DeepSeek retrained its flash model for agents and coding. The orchestration and interoperability layer (MCP, A2A, agent frameworks) is becoming the next platform battle. ([LLM Stats](https://llm-stats.com/ai-news))

**Why it matters.** Agents are where the next revenue is underwritten, because a tool that produces a deliverable can command a salary-sized price. They are also where the new risk lives, since an agent that acts can act badly, which is why the agent and observability layers are rising together.

**Where it is heading.** Watch agent pricing, the move from "embed" to "operate," and whether trust and control become the thing that decides which agents enterprises actually deploy.
